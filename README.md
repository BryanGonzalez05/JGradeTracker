This project allows The user to Add, Delete, and Check for students information. 
The information includes the students full name, student ID, and Student GPA.
Using a system base OS and uses the scanner method to take user input.
When checking for students information you can also view the students gpa.
Viewing the students gpa allows you to see the top 5 student GPA's or the bottom 5 Student GPA's.
As well as ordering them from highest to lowest or lowest to highest.
